# /harness-check — Validate current harness

Check harness health without making changes.

## Instructions

Run the validation:
```bash
~/.harness-toolkit/bin/harness check
```

Report the results clearly:
- Show PASS/WARN/FAIL counts
- List any specific issues
- Show harness info (tier, version, last updated)
- If there are warnings about placeholder files, offer to generate the content now
