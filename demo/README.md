# Demo

Each subdirectory is a standalone example showing how the toolkit behaves on different project types.

## Contents

- `test-1/` — Example minimal-tier initialization on a simple shell project
- `bugs/` — Historical bug reproductions for regression testing

# Follow the README inside each subdirectory
